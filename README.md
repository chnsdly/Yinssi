# 隐肆

Hugo 中文写作网站。文章保存在 `content/posts/`，一篇文章一个文件夹。

## 开始使用

在项目目录打开终端，运行：

```powershell
hugo server
```

打开 **http://localhost:1313/**。保存修改后，Hugo 自动更新预览；关闭时按 `Ctrl+C`。需要预览草稿时使用 `hugo server -D`。

网站名称在 `hugo.toml` 的 `title` 中修改，首页短句在 `homeSentence` 中填写，短句在顶栏下方的页面空间中上下、左右居中。

宽度达到 1280px 时显示三栏，较窄的窗口使用两侧抽屉。左侧文章列表按年份折叠，年份和年内文章均从新到旧排列。点击“隐肆”返回首页时，自动清除标签筛选，收起标签索引和全部年份列表，并将列表滚动位置归零。

桌面栏宽按窗口分配：1280–1439px 时，文章栏 240px、本文目录 208px，栏间距和外侧留白各 32px；1440px 起，文章栏 288px、本文目录 256px，栏间距和外侧留白各 40px，整体最大宽度 1400px。正文最大宽度保持 684px。各列表预留滚动条空间，避免条目因滚动条出现而重新换行；首页以左右对称的栏位保持短句居中。

左栏的“按标签浏览”会原位展开文字索引，只列出标签及其文章数量。选择后自动收起并展开匹配的年份，正文保持原位；点击当前标签旁的“×”，或再次选择已选标签，恢复完整列表及之前的归档折叠位置。进入下一篇文章时保留当前标签，筛选不会修改文章中的标签。左右两栏的标题和列表起点对齐。

标签、文章标题及本文目录条目统一使用 14px 字号、24px 行高和上下各 8px 留白，单行高 40px，长文字自然换行增高。各栏的一级列表文字均从左侧 16px 起排，区域标题为 13px、数量数字为 12px；目录子级保留额外缩进。

搜索始终位于顶栏右侧，窄屏只显示搜索图标，与左侧的“隐肆”相对。触摸设备上右滑打开文章列表、左滑打开本文目录，反向滑动或点击留白关闭侧栏，正常阅读时不显示“文章 / 目录”菜单；鼠标设备的窄窗口保留可点击的导航入口，键盘和屏幕阅读器也能使用导航按钮。搜索覆盖全部文章的标题和正文，与左栏筛选独立。结果显示标题及高亮的命中片段，关闭面板会恢复原来的阅读位置。

## 写文章

在项目目录打开 PowerShell，执行：

```powershell
hugo new content --kind posts posts/your-article-slug
```

打开生成的 `content/posts/your-article-slug/index.md`，填写标题、日期和正文。小标题从 `##` 开始，Hugo 构建时会按解析后的标题结构检查，代码块中的 `#` 不受影响。

```yaml
---
title: "文章标题"
date: 2026-11-12T09:00:00+08:00
draft: true
tags: []
---
```

日期用于文章排序、年份分组及发布判断，文章页面不显示日期。

需要正文插图时，将图片放在本篇文件夹中，用 `![说明](image.jpg)` 引用。

定稿时把 `draft` 改为 `false`，检查并构建：

```powershell
node scripts/verify-content.mjs
node scripts/build.mjs
```

构建结果生成到 `public/`，排除草稿、未来日期和已过期文章。无效站内链接和锚点会报错。修改文章时保留原始日期和目录名，网址不会随标题变化。

全文搜索索引在正式构建时生成，`hugo server` 本身不更新搜索索引。

## 网站文件

| 位置 | 用途 |
| --- | --- |
| `content/posts/` | 文章与正文插图 |
| `hugo.toml` | 网站配置、首页短句 |
| `archetypes/` | 新文章模板 |
| `layouts/` | 页面模板 |
| `assets/` | 排版样式和页面交互 |
| `scripts/` | 正式构建、搜索索引和内容检查 |
| `node_modules/` | 搜索和构建依赖 |

运行时会自动生成 `.cache/`（缓存）与 `public/`（构建结果），二者都可以重新生成。

## 重新安装

当前目录已准备好依赖。迁移到另一台电脑时，安装 Hugo Extended（建议 0.169.0）与 Node.js 24.22.1，在项目目录运行：

```powershell
npm ci
hugo server
```

预览与构建均使用环境中已安装的 Hugo。Pagefind 1.6.0 等依赖由锁文件固定。
